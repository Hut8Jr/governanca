## 🧭 Modelo de trabalho

- Os squads são multidisciplinares e podem atuar em diferentes tipos de projeto.
- Os projetos listados representam o histórico ou o foco atual, não uma limitação de atuação.
- Cada squad possui um líder responsável pela organização operacional e pelo acompanhamento das entregas.
- O Diretor de Projetos mantém acesso administrativo transversal quando necessário; esse acesso não implica participação operacional no squad.
- O contador registra projetos, não repositórios. Por isso, Auto Repair conta como um projeto, embora possua MVP e API separados.
